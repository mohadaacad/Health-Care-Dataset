📌 Overview

This dataset contains information related to healthcare service access and patient satisfaction, particularly focusing on HIV/AIDS service delivery. It includes demographic characteristics, service accessibility factors, and multiple dimensions of patient satisfaction.

The dataset is useful for descriptive analytics, public health research, and health service quality evaluation.

📊 Dataset Summary

Number of observations: 205

Number of variables: 16

Data format: .dta (Stata file)

🧾 Variables Description

👤 Demographic Information

Age – Age of the respondent

Sex – Gender (Male/Female)

Marital_status – Marital status (e.g., Married, Divorced, Widow)

Education – Level of education

Occupation – Employment status

🏥 Healthcare Access

Enrolled_HIVAIDS – Duration of enrollment in HIV/AIDS program

Distance – Distance to healthcare facility

Transport – Cost of transportation

Time_Spent – Time spent accessing healthcare services

⭐ Patient Satisfaction Indicators

Satisfaction_Time – Satisfaction with waiting time

Satisfaction_Counseling – Satisfaction with counseling services

Satisfaction_Privacy – Satisfaction with privacy

Satisfaction_StaffPatient – Interaction with healthcare staff

satisfaction_Physicalenvironmen – Physical environment satisfaction

Satisfaction_ARTavailability – Availability of ART (treatment)

📈 Overall Outcome

Satisfiedoverallquality – Overall satisfaction (YES/NO)

🎯 Purpose of the Dataset

This dataset can be used to:

Analyze patient satisfaction levels

Evaluate healthcare service quality

Identify barriers to accessing healthcare

Support policy and decision-making in public health

📌 Example Use Cases

Descriptive analysis (frequency, percentages)

Dashboard creation in Excel or Power BI

Identifying key drivers of satisfaction

Comparing satisfaction across demographic groups

⚠️ Notes

Some variables contain categorical text values (e.g., “Very satisfied”, “Dissatisfied”)

Data cleaning may be required (e.g., spelling inconsistencies like “Disstatisfied”)

Suitable for beginner to intermediate data analysis projects
